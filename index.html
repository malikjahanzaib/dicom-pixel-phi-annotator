What is exported?

Native-pixel boxes grouped by combo and image size. Boxes from every sample and frame are merged and exact duplicates removed, so the result is a layout — not a frame-by-frame recipe. Every annotated file needs a combo ID. Use a backup to preserve frame ownership, and Preview to confirm the merged layout covers the text.
